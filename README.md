# Headset Academy

Self-paced contact center training: TSR L1-L3, CSR and Bilingual Spanish, with flow diagrams, call scripts, QA checklists, flashcards, live practice calls and QA scoring.

Static site, no build step. Open `index.html` or serve the folder (for example `python -m http.server`).

- **Plan:** 26 weeks, see [SYLLABUS.md](SYLLABUS.md). Lessons are in `js/app.js`; weeks are in `js/plan.js`.
- **Voice:** browser speech (read aloud everywhere, speaking in Chrome/Edge).
- **Live AI calls:** paste your own Anthropic API key in Settings. It is stored only in your browser. Never commit a key.
- **Progress:** saved in your browser. Export and import a backup in Settings.
